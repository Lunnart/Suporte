#Este projeto reúne vários programas Java, principalmente o sistema Bytebox, o Suporte, a Avaliação de Atendimento e a consulta dos Bairros de Fortaleza
em uma página HTML única e funcional.

Ela inclui:

🖥️ Página inicial do Bytebox
👤 Cadastro
🛠️ Montagem do PC
🛒 Carrinho com cálculo do total
🔧 Sistema de suporte com ordem de serviço
⭐ Avaliação de atendimento
📍 Consulta de valor do frete de acordo com o bairro em Fortaleza

O conteúdo inclui os produtos, preços e lógica de regionais de Fortaleza.

#Para testar no seu computador abra e baixe o index.html, salve o arquivo e abra com o navegador. Não precisa instalar Java para essa versão.
